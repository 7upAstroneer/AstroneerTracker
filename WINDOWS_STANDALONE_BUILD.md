# Building the Windows Standalone Version

This repository includes a Windows PyInstaller build configuration.

1. Extract/clone the repository on Windows.
2. Install Python 3 if it is not already installed.
3. Double-click `BUILD_WINDOWS_STANDALONE.bat`.
4. Wait for the build to complete.
5. The standalone application will be in:

`dist\Astroneer Gameplay Tracker\`

Run `Astroneer Gameplay Tracker.exe` from that folder.

The entire generated folder is the standalone distribution; keep its bundled
files together when moving it to another computer.
